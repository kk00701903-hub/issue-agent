Agent Hub 이용약관(초안)

1. 서비스

Agent Hub는 고객 PC에서 AI 에이전트를 실행·관리하는 프로그램(실행기)과, 계정·요금제·기기 연결을 관리하는 웹 콘솔로 이루어집니다.

2. 요금과 기간

가입하면 14일 평가판을 씁니다. 유료 요금제는 결제 확인 시점부터 31일 단위로 적용됩니다. AI 모델 사용료(API)는 고객이 직접 계약한 제공자에게 따로 냅니다.

3. 고객의 책임

게시·제출·결제 같은 최종 행동은 고객이 직접 합니다. 고객은 각 플랫폼(인스타그램 등)의 이용약관을 지켜야 하며, 자동 게시·자동 팔로우 같은 약관 위반 자동화에 이 서비스를 쓰지 않습니다.

4. 결과물

에이전트가 만든 결과물의 권리와 책임은 고객에게 있습니다. 사실 확인이 필요한 내용은 고객이 확인한 뒤 씁니다. 투자 연구 도구의 결과는 투자 조언이 아닙니다.
