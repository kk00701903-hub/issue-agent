자주 묻는 것

인스타그램에 자동으로 올려 주나요?

아니요. 자동 게시·자동 댓글·자동 팔로우·DM 자동 발송은 하지 않습니다. 이런 자동화는 계정이 막히는 지름길이라 일부러 뺐습니다. 승인한 결과의 캡션과 소개 댓글을 복사하고, 인스타그램 앱의 콘텐츠 예약으로 직접 올립니다.

AI 사용료는 따로 드나요?

네. 에이전트는 고객님 PC에서 고객님의 Claude API 키로 돕니다. 하루 한도를 정해 두면 그 이상은 쓰지 않습니다. 시험 실행(드라이런)은 비용이 들지 않습니다.

제 원고나 자료가 서버로 가나요?

아니요. 원고·패키지·파일은 PC에만 남습니다. 웹 콘솔은 요금제 확인을 위해 실행 건수 같은 개수만 받습니다.

인터넷이 끊기면 멈추나요?

이용권은 PC에 저장돼 있어 기간 안에는 그대로 돕니다. 기간이 지나도 7일 유예가 있고, 인터넷이 안 되는 PC는 오프라인 토큰을 받아 넣을 수 있습니다.

Mac에서도 되나요?

지금은 Windows PC 기준으로 설치 안내를 드립니다. Python이 돌아가는 PC면 실행은 되지만, 설치 파일과 안내는 Windows부터 냅니다.
