# 영상 「Grok 에이전트 트레이딩 팀」 분석 + 깃허브 도구 8개 (2026-11-03)

## 1. 영상 분석 — 「누군가 그록 에이전트로 트레이딩 팀을 만들어 89달러를 맡겼는데 6만 8천 달러」 (35초)
화면 글자·장면으로 파악(음성 인식 모델을 이 환경에서 못 받음).

| 장면 | 내용 | 우리에게 쓸 것 |
| --- | --- | --- |
| 팀 구성 | 에이전트 6개(TESS·RIGO·ILSA·HOLT·KETT·BRAM)에게 역할 배정 「역할 배정 3/6」, 「6개 연결됨」 | 모니터에 「역할 배정 n / m」 표시 |
| 역할 | 스캐너(시장 훑기)·비중(얼마나)·진입(언제)·리스크 가드(무리한 매매 막기, 「고위험」 표시) | 투자 연구 그룹을 같은 역할 팀으로 나눔(백테스트만), 모니터에 「리스크 가드 — 훅이 막은 것」 칸 |
| 트레이딩 층 화면 | 책상마다 픽셀 캐릭터, 잔액 그래프, 활동 기록, 「수동 주문 0회」 | 모니터 카드 벽(픽셀 캐릭터)과 같은 방식, 「사람 확인(오늘)」 숫자 |
| 작업 타이머 | 「2h 41m 07s」처럼 초 단위로 도는 가동 시간 | 모니터에 「오늘 가동 시간」(1초마다 갱신) |
| 역할 문서 | scan.md·size.md·entry.md·guard.md — 역할마다 문서 하나 | 우리는 이미 `.claude/agents/<이름>.md` 로 같은 구조 |
| 끝 | 「댓글에 『트레이딩』이라고 남기면 가이드 보내 드릴게요」 | 댓글→DM 흐름(docs/benchmark-dm-funnel.md)과 같음 |

**넣지 않은 것과 이유**
- 실제 돈으로 자동 매매하는 부분은 넣지 않았다. 「89달러 → 6만 8천 달러」는 영상의 주장일 뿐 확인할 수 없고, 짧은 기간 큰 수익을 앞세운 홍보는 손실 위험을 빼고 말하는 경우가 많다. 투자 연구 그룹은 **백테스트·모의 매매·보고서까지만**, 주문·이체·거래소 키는 금지(코드 정의의 금지 항목).

## 3. 바뀐 것
- `hub/agents.json`: market-terminal·ml-intern·desktop-operator 추가, lesson-maker 에 DeepTutor, 투자 연구 그룹을 역할 팀(시장 스캐너·비중 계산·진입 계획·리스크 가드·백테스트)으로.
- 모니터: 역할 배정 n/m, 사람 확인(오늘), 오늘 가동 시간(초 단위), 리스크 가드 칸.

## 4. 추가: agent-desktop (영상 「AI에게 손을 달아주는 오픈소스」, 2026-11-03)
- 무엇: Vercel Labs 오픈소스(npm `agent-desktop`, v1.0.2, Labs 실험 단계). 맥·윈도우·리눅스 데스크톱 앱을 **접근성 트리**로 읽고 조작한다 — 스크린샷을 보고 좌표를 짐작하지 않고, 버튼마다 고정 번호(ref)를 받아 누르니 덜 틀리고 토큰도 아낀다. 기본이 백그라운드 실행이라 사람은 계속 일할 수 있고, 에이전트 여러 개가 각자 커서로 동시에 움직일 수 있다.
- 설치: `npm install -g agent-desktop` → `agent-desktop version`. 맥은 손쉬운 사용 권한 필요(`agent-desktop permissions --guide`), 윈도우는 별도 권한 없음.
- 반영: 공통 `desktop-operator`(격리 PC 조작 → 데스크톱 조작)의 기본 도구로. 위험한 작업은 기존대로 cua 격리 PC.
- 지킬 것: 최종 버튼(게시·제출·결제·삭제·보내기)은 사람, 인스타·카카오톡·LINE 같은 수익 계정 앱은 조작하지 않음, 비밀번호 입력 금지. 이 금지는 훅으로 막아야 하는데 훅 파일은 지금 작업 환경에서 고칠 수 없어 **에이전트 정의의 금지 항목으로만** 걸어 두었다 — 켜기 전에 훅에 `agent-desktop click/type` 검사를 넣어야 한다(사용자 허락 후).
- 영상 형식에서 배울 점: 장면마다 노란 라벨로 「출처: @계정」을 붙인다 → 우리 릴스도 남의 화면·자료를 쓰는 장면에 출처 라벨(docs/reels-format-ranking.md 의 출처 카드와 함께). 끝은 「댓글에 『DESKTOP』 남기면 정리글+사용법 DM」 — 댓글→DM 흐름과 같음.
