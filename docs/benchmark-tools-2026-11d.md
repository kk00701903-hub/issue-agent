## 알림 쓰는 법
1. 설정 → 화면 → 「데스크톱 알림 켜기」 → 브라우저가 묻는 창에서 「허용」.
2. 앱(또는 크롬 탭)이 열려 있으면 승인 기다림·훅 차단이 생길 때 Windows 알림이 뜬다. 앱을 완전히 닫으면 오지 않는다.
3. 처음 화면을 열 때 이미 있던 건은 알리지 않는다(새로 생긴 것만).
