# AI 미디어 스튜디오(Open Generative AI) 설치·사용

작성 2026-11-01. 참고 글: lazyowen.com 「Open Generative AI」 가이드. 저장소: https://github.com/Anil-matcha/Open-Generative-AI (MIT, 별 약 3.2만, 데스크톱 v2.0.0 기준).

## 1. 무엇인가
이미지·영상 모델 200개가 넘게 한 화면에 모은 무료 데스크톱 앱. 클라우드 생성은 muapi.ai 계정·키로 돌고, 설치판에서는 내 PC 엔진(sd.cpp 그림, Wan2GP 영상)으로도 돌린다.

| 탭 | 하는 일 |
| --- | --- |
| Image Studio | 글→그림, 그림 고치기 |
| Video Studio | 글→영상, 그림 한 장 움직이기 |
| Cinema Studio | 카메라·렌즈(8~85mm)·조리개(f/1.4~f/11) 값을 넣어 영화 같은 화면 |
| Lip Sync Studio | 얼굴 사진·영상 + 음성 → 말하는 영상(모델 9개) |

## 2. 우리 작업에서 쓰는 곳(기본 도구 규칙은 그대로)
- **그림 생성은 Firefly**, **영상 생성은 Kling(MCP 커넥터)** 이 기본이다. 이 앱은 그 둘을 대신하지 않는다.
- 쓰는 곳
  - **립싱크**: 게임 컷씬 인물·직접 만든 캐릭터에 음성 입히기(Kling·Firefly 에 없는 기능).
  - **카메라 값 시안**: Cinema Studio 의 렌즈·조리개 값을 컷씬·릴스 프롬프트 표준으로 옮겨 적기.
  - **로컬 엔진 비교 시안**: 크레딧 없이 PC 그래픽카드로 돌려 보는 시험(사용자가 따로 요청할 때만).
- **금지**: 실존 인물(대통령·지도자·연예인 등) 얼굴 립싱크. top.pick01 인물 릴스에 쓰면 조작 영상이 된다.

## 3. 설치(사람이 한다)
1. 공식 저장소 Releases 에서만 받는다(다른 내려받기 링크 금지).
2. Windows 파란 경고 → 「추가 정보」 → 「실행」(서명이 없어서 뜨는 경고).
3. 무료 계정으로 로그인해야 클라우드 모델이 보인다.
4. 자동화가 필요하면(선택):
   ```
   npm install -g muapi-cli
   muapi auth configure        ← 키 입력은 사람이 직접(에이전트·명령줄에 키를 쓰지 않음)
   muapi image models          ← 모델 이름이 나오면 연결 성공
   ```
5. 설치한 버전을 `hub/rules.json` 에 적어 고정한다(앱 판이 자주 바뀜).

## 4. 비용·주의
- 앱은 무료(MIT). 무거운 클라우드 모델은 크레딧이 들 수 있다 — 결제·크레딧 구매는 사람이 한다.
- 올린 파일은 클라우드 모델을 쓰면 muapi 서버로 간다. 미공개 원고·고객 자료는 올리지 않는다.
- 키는 앱(브라우저 저장소)에 저장되고 muapi 로만 보낸다고 저장소에 적혀 있다. 키를 파일·프롬프트·저장소에 적지 않는다.
- Wan2GP 를 다른 PC에서 원격으로 쓸 때 `--mcp-host 0.0.0.0` 은 믿을 수 있는 네트워크에서만.
- 로컬 그림 모델 Z-Image 는 메모리 약 16GB 필요. 영상 로컬 엔진은 NVIDIA·AMD 그래픽카드 필요.

## 5. Agent Hub 연결 상태
- 공통 그룹에 `media-studio`(「AI 미디어 스튜디오」, 예정)를 추가했다. 실행기에는 아직 연결하지 않았다.
- **훅(안전장치)은 아직 넣지 못했다**: 「muapi 키를 명령줄에 쓰면 막기」, 「muapi image/video 생성 명령은 막기(Firefly·Kling 규칙)」를 `.claude/hooks/pre_tool_guard.py` 에 넣으려 했으나, 작업 환경이 훅 파일 수정을 허락하지 않았다. 사용자가 허락하면 넣는다. 그 전까지 이 에이전트는 켜지 않는다.
