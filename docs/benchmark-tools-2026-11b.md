## 도구별 규칙
**VoiceStudio**
- 쓰는 곳: 참고 영상 받아쓰기(지금까지 이 환경에서 음성 인식 모델을 못 받아 화면 글자로만 파악했음 → PC에서 로컬로 해결), 웹소설 회차 오디오북 시안, 릴스 더빙 시안.
- 릴스 기본 음성은 그대로(본계정 SunHi, top.pick03 Chirp3-HD).
- **목소리 복제는 본인 목소리나 허락받은 목소리만.** top.pick01 인물(대통령·지도자) 목소리 복제 금지.
- AGPL 이라 Agent Hub(판매용) 코드에 섞지 않는다. 따로 설치해 로컬 API·MCP 로만 부른다.

**Paperclip — 본체에 들인 것**
- 에이전트별 하루 한도: `hub/config.json` 의 `agent_budgets_usd` (기본 reels-maker 3달러). 넘으면 그 에이전트 실행만 멈추고 다른 에이전트는 계속. 모니터 카드와 설정 → 운영 한도에 사용량이 보인다.
- 조직도: 모니터 연결도에서 가운데 허브 → 그룹 리드 → 에이전트로 이어진다.
- 「정기 깨우기(heartbeat)」는 넣지 않았다 — 게시·예약은 사람이 인스타 「콘텐츠 예약」으로 한다는 규칙 때문. 필요하면 트렌드 조사처럼 게시와 무관한 일에만 따로 정한다.

**Vibe-Trading — 넣되 백테스트만**
- 실거래(Live Trading) 기능은 끈다. 주문·이체·거래소 키는 에이전트가 다루지 않는다(금지 항목).
- 결과는 투자 조언이 아니다. 1.0 이전 판이라 실제 자금 전에 검증이 더 필요하다고 카드도 적고 있다.

**God's Eye View**
- 개인 위치 추적·특정인 주소 조회에는 쓰지 않는다. 라이선스는 카드에 없어 쓰기 전 저장소에서 확인.

**OpenMAIC**
- 모델 키가 하나 필요(Anthropic·DeepSeek·Qwen 등 지원). 미공개 원고를 넣을 땐 Claude 또는 `local` 만 (docs/alt-models.md 등급 규칙).
- 쓰는 곳: 자동화 가이드북 강의 슬라이드, 한국사 게임의 한능검 학습 콘텐츠 시안.

**Magnitude**
- 설치 스크립트를 셸에 바로 넣는 방식(`curl … | sh`)이라, 먼저 스크립트를 읽어 본 뒤 설치하거나 설치 파일(.exe)을 받는다.
- 설치 후 `hub/config.json` 의 `providers.local.base_url` 을 Magnitude 가 알려 주는 주소로 맞추고, `model_routes` 에서 작업을 `local` 로 돌린다. `local` 은 127.0.0.1 주소만 허용(코드가 막음).

**Open SEO**
- DataForSEO 유료 API 키가 필요하고(직접 설치해도 사용료 발생), 네이버 자료는 없다. 국내 판매 페이지에는 효과가 제한적이라 예정으로만 둔다. 결제는 사람이.

## 같이 들어간 것
- 모니터 화면(요청: 「에이전트들이 일하는 거 시각적으로 모니터링」): 전체 처리율 막대, 에이전트 카드 벽(픽셀 캐릭터·상태·진행 막대·한도), 별자리 연결도(작업 중이면 선 위로 점이 흐르고 노드가 빛남, 누르면 최근 작업이 위성처럼 돎), 릴스 흐름 단계별 건수, 최근 6시간 활동 그래프, 전체 화면(벽 모니터용).
