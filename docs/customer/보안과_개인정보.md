# 보안과 개인정보

## 고객 PC에만 있는 것
원고·릴스 패키지·주제·결과 파일·작업 기록·API 키(.env). 웹 콘솔로 보내지 않습니다.

## 웹 콘솔로 가는 것(15분마다)
실행기 버전, 기기 ID, PC 이름, 켜진 도구 ID, 오늘 실행 건수(상태별 개수), 작업 중 에이전트 수. 이용권 확인에만 씁니다.

## 막혀 있는 것(훅)
- 게시·공유·제출·등록·결제·삭제 버튼 클릭(크롬·데스크톱 앱 모두). 허용 예외(약관 동의·임시저장 등)는 `hub/rules.json`.
- 수익 계정 앱(인스타그램·카카오톡·LINE) 데스크톱 조작, 비밀번호 입력
- 인스타그램·X·페이스북 화면 수집(계정 보호)
- git commit/push, 파일 삭제, hub/·.claude/ 규칙 수정

## 관리 화면
`127.0.0.1` 에서만 열립니다(같은 PC). 다른 사람과 같이 쓰는 PC면 `.env` 의 `HUB_PASSWORD` 를 정하세요. 「휴대폰으로 보기」(`HUB_LAN=1`)는 비밀번호가 있을 때만 켜지고, 집·사무실 공유기 안 주소(192.168.x.x 등)에서 온 접속만 받으며, 로그인해야 화면이 열립니다. 공유기 밖(인터넷)에서는 들어올 수 없습니다.
