# 빠른 시작 — 10분

1. **도구 켜기** — 관리 화면 왼쪽 「도구」. 쓸 도구를 펼쳐 「켜기」. 요금제에 없는 도구는 웹 콘솔에서 요금제를 올리면 켤 수 있습니다.
2. **에이전트 연결** — 같은 화면에서 일할 에이전트를 눌러 연결합니다. 「기본 실행」 표시가 붙은 에이전트는 꼭 연결돼 있어야 합니다.
3. **(인스타그램) 계정 등록** — 도구 → 인스타그램 → 계정에 계정 ID·이름·음성 여부를 넣고 저장. 로그인 정보는 받지 않습니다. 금지 BGM·읽기 속도 같은 검수 규칙도 여기서 정합니다.
4. **시험해 보기(비용 없음)** — 「1. 만들기」에서 도구를 고르고 「통과 예시로 시험」. 2~4단계 흐름을 가짜 결과로 확인합니다.
5. **실제로 맡기기** — 「1. 만들기」의 명령을 복사해 설치 폴더의 cmd 창에 붙여 넣습니다. 끝나면 「2. 진행 확인」에 나타납니다.
6. **승인** — 「3. 승인하기」에서 검수 결과와 내용을 보고 승인·반려합니다.
7. **게시(인스타그램)** — 「4. 게시하기」에서 캡션·소개 댓글을 복사하고, 인스타그램 앱의 콘텐츠 예약으로 직접 올립니다.

## 모니터
「모니터 → 사무실」에서 에이전트가 실제로 일하는 모습을 봅니다. 맡은 일이 진행 중이거나 최근 2분 안에 도구를 쓴 에이전트는 타자를 치고, 승인을 기다리면 손을 듭니다.

## 휴대폰으로 보기
같은 와이파이에 연결된 휴대폰에서도 오늘 할 일·승인·모니터·인사를 볼 수 있습니다. `.env` 에 `HUB_PASSWORD`(비밀번호)와 `HUB_LAN=1` 을 넣고 관리 화면을 다시 켜면, 설정 → 「휴대폰으로 보기」에 휴대폰에서 열 주소가 나옵니다. 휴대폰에서는 아래 탭 막대(오늘·진행·승인·모니터·더보기)로 움직이고, 브라우저의 「홈 화면에 추가」로 앱처럼 쓸 수 있습니다. 바깥 인터넷에는 열리지 않습니다.

## 비용 관리
설정 → 운영 한도에서 하루 API 한도와 에이전트별 한도를 봅니다. 넘으면 실행이 멈춥니다(`hub/config.json`).
