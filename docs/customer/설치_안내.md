# 설치 안내 (Windows)

## 준비물
- Windows 10/11 PC
- Python 3.10 이상(python.org 에서 설치, 설치할 때 「Add Python to PATH」 체크)
- Claude API 키(console.anthropic.com) — AI 사용료는 이 키로 따로 나갑니다
- 선택: Node.js(크롬 조작·영상 렌더링을 쓸 때), Google Chrome

## 설치
1. 받은 압축 파일을 풀어 원하는 폴더(예: `C:\AgentHub`)에 둡니다.
2. 폴더 안의 `install.bat` 을 두 번 누릅니다. 필요한 것을 설치하고 `.env` 를 만듭니다.
3. `.env` 를 메모장으로 열어 `ANTHROPIC_API_KEY=` 뒤에 키를 넣고, 다른 사람과 같이 쓰는 PC면 `HUB_PASSWORD=` 에 관리 화면 비밀번호를 넣습니다.
4. `run.bat` 을 두 번 누르면 브라우저에 관리 화면(`http://127.0.0.1:4830`)이 열립니다. 이 주소는 이 PC 안에서만 열립니다.

## 이용권 연결
1. 웹 콘솔에 가입합니다(14일 평가판).
2. 콘솔 → PC 연결 → 「PC 연결 코드 받기」.
3. 관리 화면 → 설정(오른쪽 위 톱니) → 웹 콘솔 연결에 콘솔 주소와 코드를 넣고 「연결」.
4. 끝. 15분마다 자동으로 이용권을 새로 받습니다.

## 켤 때마다 자동으로
`autostart-on.bat` 을 누르면 Windows 를 켤 때 Agent Hub 도 같이 켜집니다(끄려면 `autostart-off.bat`).

## 업데이트
새 버전 압축 파일을 같은 폴더에 덮어씁니다. `data\` 폴더(작업 기록·설정)와 `.env` 는 그대로 둡니다.
