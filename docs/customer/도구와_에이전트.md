# 도구와 에이전트

도구에 연결한 에이전트만 그 도구의 일을 맡습니다. 공용 에이전트는 요금제와 상관없이 들어 있고 아무 도구에나 연결합니다.

## 📱 인스타그램 릴스·카드뉴스

주제만 넣으면 후킹·장면·대본·캡션·소개 댓글까지 든 릴스 패키지를 만들고, 장면 속도·캡션 링크·해시태그·BGM 규칙을 코드로 검수해 승인함에 올립니다.

- 기본 실행 에이전트: `reels-maker` · 결과: `package.json`

| 에이전트 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 트렌드 조사 (`trend-scout`) | 당일 급상승 주제를 조사해 주제 후보 3개와 근거 링크를 낸다. 잘 된 경쟁 릴스·쇼츠는 web-reader로 자막을 읽어 구조(첫 3초·장면 순서)만 참고한다. 도구 설정의 관심 주제를 우선한다. | 패키지 작성, 브라우저 조작 |
| 릴스 제작 (`reels-maker`) | 계정과 주제를 받아 패키지(후킹·장면·대본·BGM 지정·캡션·소개 댓글)를 만든다. | 커밋, 삭제, 게시, 예약, hub/·.claude/ 수정 |
| 규칙 검수(코드) (`reels-validator`) | 금지 BGM·로테이션, 캡션 링크, 장면 속도, 순서 표시, 계정별 필수 항목을 코드로 검사한다. | - |
| 의견 검수 (`reels-reviewer`) | 후킹의 관련성·교훈, 사실 확인 필요 표시 등 코드가 못 잡는 부분을 읽고 의견만 낸다. | 파일 수정 |
| 영상 제작 (`reels-renderer`) | 승인된 패키지로 사진·TTS 음성·BGM을 합쳐 세로 영상(1080×1920)을 만든다. 렌더링은 HyperFrames(HeyGen, Apache-2.0, 고객 PC에 따로 설치: HTML·CSS·JS → MP4)로 — 장면 글자·사진 펀치 줌·숫자 도장 같은 움직임을 코드로 만들어 영상 생성 AI 없이 만든다. 형식 틀: 「TOP10 랭킹 카운트다운」(tools/instagram/docs/reels-format-ranking.md), 「진행자 + 위 카드 해설」(tools/instagram/docs/reels-format-explainer.md). | 게시, 예약, 계정 설정의 금지 BGM 사용, 장면 속도 규칙 무시 |
| 인스타 예약 보조 (`insta-scheduler`) | 브라우저로 인스타 콘텐츠 예약 화면을 열어 영상·캡션·일시를 채우고 소개 댓글 문구를 준비한다. 마지막 「예약/공유」 버튼은 사람이 누른다. | 게시·예약 버튼 누르기 |
| 댓글→DM 자동 응답 (`dm-funnel`) | 릴스마다 댓글 키워드·DM 문구·팔로우 확인 단계를 설계한다(벤치마킹: 「팔로우 확인」 버튼 → 팔로우 여부 확인 → 자료·링크 전송). 링크는 캡션이 아니라 DM으로 보낸다. 설정은 ManyChat 등 Meta 공식 API 도구에서 하고 마지막 「켜기·게시」는 사람이 누른다. | 비공식 봇·비밀번호 로그인, 팔로우만 한 사람에게 먼저 DM, 무한 재확인, 켜기·게시 버튼 누르기 |
| 인스타 스킬 13종 (`insta-skills`) | instagram-agent-skill(MIT, 키·로그인 없음) 13개 스킬을 우리 규칙에 맞춰 쓴다 — 지난 게시물 분석(ig-audit), 캡션 점검(ig-caption), 프로필 점수(ig-profile), 주간 계획(ig-plan→캘린더), 레퍼런스 릴스 순위(ig-viral, 사람이 모은 자료로만), 답글·스토리·재활용 초안. 글만 쓰고 게시·댓글·팔로우·DM은 사람이 한다. | 인스타 로그인·자동 게시·자동 댓글·자동 팔로우, 에이전트가 인스타 화면 수집, 우리 후킹 규칙보다 스킬 기본값 우선 |

따로 설치해 쓰는 외부 도구: Edge TTS(음성)(MIT), HyperFrames(영상 렌더링)(Apache-2.0), instagram-agent-skill(MIT)

| 검색 노출 점검 (`seo-check`) | Open SEO(MIT)로 판매 페이지·블로그의 키워드·순위·사이트 점검을 한다. DataForSEO 유료 API 키가 필요하고 네이버 데이터는 없다(구글 기준). | 결제·요금제 변경, 사이트 글 자동 수정 |

## 🧑‍💼 크몽 전문가 서비스

크몽에 올릴 서비스 자료(제목·요약·상세 설명·3단 패키지·FAQ·미리보기 목록)를 만들고 크몽 등록 규칙(외부 연락처·절대 표현·패키지 가격 차이·최소 금액)을 코드로 검수한 뒤, 승인하면 등록 화면을 임시저장까지 채웁니다. 「검수 요청」 버튼은 사람이 누릅니다.

- 기본 실행 에이전트: `kmong-planner` · 결과: `package.json`

| 에이전트 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 크몽 시장 조사 (`kmong-researcher`) | 같은 카테고리의 공개 서비스 페이지(제목·가격대·패키지 구성·리뷰 수)를 읽어 가격대와 차별점을 정리한다. 남의 문구·이미지는 베끼지 않는다. | 남의 서비스 문구·이미지 복제, 로그인 화면 수집 |
| 서비스 자료 작성 (`kmong-planner`) | 주제·판매 형태를 받아 제목·카테고리·요약·상세 설명·3단 패키지(가격·작업일·수정 횟수·제공 내용)·FAQ·검색 키워드·미리보기 목록을 package.json 으로 만든다. 저장 뒤 검수기로 오류가 0이 될 때까지 고친다. | 외부 연락처·외부 결제 유도 문구, 증빙 없는 경력·수익 주장, 크몽 화면 조작 |
| 크몽 규칙 검수(코드) (`kmong-checker`) | 외부 연락처(전화·메일·SNS·링크), 절대 표현(최고·최초·유일 등), 무조건 보증 표현, 「문의주세요」 가격, 패키지 간 가격 차이 1만 원 이상, 판매 형태별 최소 금액, 전자책 미리보기 5장 이상을 코드로 검사한다. | - |
| 크몽 등록 화면 채우기 (`kmong-uploader`) | 승인된 자료로 크몽 판매자 서비스 등록 화면을 브라우저로 채우고 임시저장까지 한다. 「검수 요청」·「판매 시작」·가격 변경 저장은 사람이 누른다. | 검수 요청·판매 시작 버튼 누르기, 비밀번호 입력, 메시지 답장, 주문 수락 |
| 문의 답장 초안 (`kmong-reply-draft`) | 사람이 붙여 넣은 의뢰인 문의에 답장 초안을 쓴다(외부 연락처·외부 결제 유도 없이). 보내기는 사람이 한다. | 메시지 보내기, 외부 연락처 안내, 주문 전 개인정보 요구 |

## 🤝 공용 에이전트

브라우저·웹 읽기·그림 처리 같은 공용 에이전트. 다른 도구에 연결해서 씁니다(요금제와 무관하게 포함).

| 에이전트 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| 크롬 통제 (`browser-operator`) | 사용자의 크롬(로그인 유지)을 CDP로 붙잡아 페이지 이동·읽기·입력·파일 첨부를 한다. 게시·제출·결제·삭제 버튼은 훅이 막고, 그 직전 화면에서 멈춰 승인함에 올린다. | 게시·제출·결제·삭제 클릭, 비밀번호 입력, 새 계정 로그인 |
| 웹 읽기 (`web-reader`) | Agent-Reach로 웹·유튜브 자막·깃허브를 읽기 전용으로 가져와 요약과 출처를 남긴다. 인스타·X·페이스북은 계정 보호를 위해 막는다. | 인스타·X·페이스북 채널, 게시·댓글, 키를 명령줄에 쓰기 |
| 그림·PDF 반복 처리 (`image-batch`) | PhotoCraft·PdfCraft(오픈소스, 얼리 알파) CLI·MCP로 규격 맞춤·형식 변환·일괄 보정·PSD 내보내기·PDF 합치기를 한다. 새 그림 생성은 하지 않는다(Firefly). | 원본 덮어쓰기, 그림 생성, ArtCraft 상표 사용 |
| AI 미디어 스튜디오 (`media-studio`) | Open Generative AI(MIT, muapi) 앱·muapi-cli로 립싱크(사진·영상+음성), 시네마 카메라 값(렌즈·조리개) 시안, 로컬 엔진(sd.cpp·Wan2GP) 비교 시안을 만든다. 그림 생성 기본은 Firefly, 영상 생성 기본은 Kling 그대로. | 키 다루기, 실존 인물 얼굴 립싱크, 원본 덮어쓰기, 결제·크레딧 구매, Firefly·Kling 대체 |
| 음성 스튜디오 (`voice-studio`) | VoiceStudio(AGPL-3.0, 고객 PC에 따로 설치해 로컬 API로만 부름)로 참고 영상 받아쓰기(자막·대본 뽑기), 오디오북 시안, 더빙 시안을 만든다. 도구 설정에 정한 기본 음성은 그대로 쓴다. | 남의 목소리 복제(본인 허락 없는 목소리, 실존 인물), Agent Hub 에 코드 섞기(AGPL) |
| 강의·학습 자료 (`lesson-maker`) | OpenMAIC(MIT)로 주제·자료를 넣어 슬라이드(PPTX)·퀴즈·인터랙티브 수업을 만든다. 교재·논문을 올려 질문 답변·퀴즈·개념 시각화를 하는 과외형 학습은 DeepTutor(Apache-2.0)로. | 비공개 원고를 외부 모델로 보내기(모델은 등급 규칙) |
| 격리 PC 조작 (`desktop-operator`) | 데스크톱 앱 작업을 한다. 기본 도구는 agent-desktop(npm, 실험 단계): 화면 캡처를 짐작하는 대신 운영체제 접근성 트리로 버튼·입력칸을 읽고 번호(ref)로 누른다. 쓰는 곳: 내 앱 시험, 반복 입력. 위험한 작업은 cua 격리 PC에서. | 게시·제출·결제·삭제·보내기 버튼(크롬 통제와 같은 금지어), 수익 계정 앱(인스타·카카오톡·LINE) 조작, 여러 에이전트 동시 조작으로 사람 작업 방해, 비밀번호 입력 |

| 디자인 검수 (`design-critic`) | 「AI 티 나는 디자인」(뻔한 보라 그라데이션, 같은 카드 반복, 의미 없는 아이콘)을 찾아 고칠 곳을 표시한다 — 관리 화면, 카드뉴스, 표지, 판매 페이지. | 직접 수정, 정해진 양식 바꾸기 |

따로 설치해 쓰는 외부 도구: Agent-Reach(MIT), Playwright MCP(Apache-2.0)
