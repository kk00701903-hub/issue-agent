# 판매 준비 체크리스트 (2026-11-03, v1.0.0-rc1 — SaaS 구조)

## 상품 구조
- **웹 콘솔(SaaS)**: 가입·요금제·결제·도구 선택·PC 연결·이용권 발급(`cloud/`, 판매자 서버). 원고·파일은 받지 않는다.
- **PC 실행기**: 고객 PC에서 에이전트를 돌리는 관리 화면(`hub/`). 콘솔과는 15분마다 상태 개수만 주고받는다.
- **도구**: 판매 단위(`tools/<id>`). 인스타그램·크몽 전문가 서비스·웹소설·이모티콘·굿즈·사내 개발·게임·투자 연구(베타) + 공용 에이전트. 에이전트는 도구에 연결해서 쓴다.
- **요금제**(`cloud/plans.json`, 가격은 예시): 평가판 14일(전부) → 스타터(도구 1·PC 1) → 프로(도구 3·PC 2) → 팀(전부·PC 5).
