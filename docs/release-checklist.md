# 판매 준비 체크리스트 (2026-10-31 기준)

「판매할 수 있는 수준」을 셋으로 나눴다. **1단계(지인·소수 고객 베타 판매)** 는 이번 버전으로 가능하고, **2단계(일반 판매)** 와 **3단계(기업 납품)** 는 아래 미완료 항목을 끝내야 한다.

## 이번 버전(v0.3)에서 끝낸 것
| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 설치·실행 스크립트 | 완료 | install.bat / run.bat, 표준 라이브러리만으로 화면·검수·훅 동작 |
| 관리 화면 5탭 | 완료 | 현황·승인함·흐름(편집기)·로그·설정 |
| 워크플로우 편집기 | 완료 | 추가·이동·연결·삭제·속성·저장, 자동 시험 통과 |
| 로그인 | 완료 | .env HUB_PASSWORD, 세션 쿠키(HttpOnly, SameSite) |
| 라이선스 | 완료(기본형) | 30일 평가판 → 키. HMAC 방식(아래 미완료 참고) |
| 고객사 브랜딩 | 완료 | 제품명·고객사·로고 글자·강조색을 config 로 교체 |
| 비용 한도 | 완료 | 하루 한도 초과 시 실행 거부 |
| 안전장치(훅) | 완료 | 커밋·삭제·규칙 수정·최종 버튼 차단, 단위 시험 |
| 매뉴얼 | 완료 | docs/manual.md |
| 자동 시험 | 완료 | 단위 시험(검수기·훅·흐름·라이선스) + 편집기 브라우저 시험 |

## 일반 판매 전에 꼭 끝낼 것 (2단계)
| 항목 | 왜 필요한가 | 할 일 |
| --- | --- | --- |
| 실제 에이전트 실행 검증 | `run_sdk` 는 API 키가 있는 PC에서 아직 한 번도 안 돌았다 | 외부 PC에서 실제 실행 → SDK 옵션 맞추기 → 비용 집계 확인 |
| 영상 제작 단계 | 지금은 패키지(글)까지만 만든다 | reels-renderer 를 실행기에 연결(사진·TTS·BGM 합성) |
| 라이선스 서명 방식 | HMAC 비밀이 코드에 들어 있어 역공학에 약하다 | Ed25519 공개키 서명으로 교체(`cryptography` 패키지), 키에 고객사·만료·기능 플래그 |
| 설치 패키지 | 고객이 Python 을 직접 깔아야 한다 | PyInstaller 로 exe 묶기 또는 설치 프로그램(Inno Setup), 코드 서명 인증서 |
| 업데이트 경로 | 버전 올릴 방법이 없다 | 버전 확인 + zip 교체 절차 문서, 데이터(data/)와 코드 분리 유지 |
| 약관·개인정보 | 판매 시 필수 | 이용약관, 환불 규정, 수집 정보 고지(API 키·로그는 고객 PC에만 저장됨을 명시) |
| 지원 창구 | 문의가 들어온다 | 이메일 또는 카카오 채널, 자주 묻는 질문 |
| 고객 데이터 보호 | .env 에 API 키가 평문 | Windows DPAPI 로 키 암호화 저장 검토, 로그에 키가 찍히지 않는지 점검(현재는 안 찍힘) |
| 외부 도구 고지 | Agent-Reach(MIT)·Playwright MCP(Apache-2.0)·PhotoCraft/PdfCraft(MIT·Apache-2.0, ArtCraft 상표 제외)를 고객 PC에 설치하게 한다 | 매뉴얼에 출처·라이선스 고지, 묶어서 배포하면 LICENSE 원문 동봉 |
| 브라우저 안전장치 보강 | 글자 없는 아이콘 버튼은 훅이 못 잡는다 | 사이트별 허용 URL 목록, 최종 단계 전 스크린샷을 승인함에 첨부 |

## 기업 납품 전에 끝낼 것 (3단계)
- 다중 사용자·역할(승인자/작성자), 외부 접속(HTTPS, 역방향 프록시), 감사 로그 보관 기간
- Docker 패키징과 Windows 설치 파일 둘 다(디지털 트윈 제품에서 정한 납품 형태와 동일)
- 에이전트 정의·훅·규칙을 고객이 화면에서 고칠 수 있는 설정 화면(지금은 파일 수정)
- 라이선스 서버(원격 활성화·해지)

## 가격·상품 구성(제안, 결정 필요)
- 평가판 30일 무료 → 1인 라이선스(연 단위) → 팀(승인자 다수)
- 설치 대행·초기 설정(크롬 프로필, 계정 연결)을 별도 유료 서비스로
