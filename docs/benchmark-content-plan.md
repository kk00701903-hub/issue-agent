# 벤치마킹: 「30분 만에 한 달 콘텐츠 계획」 → 캘린더 화면

작성 2026-11-01. 참고: 사용자가 보낸 릴스(roy.branding, 41초) — 화면 글자·도표로 파악(음성 인식 모델은 이 환경에서 못 받음).

## 1. 영상이 말하는 5단계
| 단계 | 내용(영상) | Agent Hub 에 넣은 것 |
| --- | --- | --- |
| #1 콘텐츠 난이도 | 쉬움·보통·어려움으로 나눈다 | 계획 만들기 창 1번 |
| #2 업로드 스케줄 | 쉬움 주 3회, 보통 주 5회, 어려움 주 7회. 오전 10시·오후 7시 칸 | 쉬움 월·수·금 / 보통 평일 / 어려움 매일, 올리는 시간 선택 |
| #3 콘텐츠 주제 | 메인 주제 하나에 하위 주제 여러 개(예: 뷰티 → 스킨케어·영양제·시술·다이어트·헤어) | 메인 주제 + 하위 주제(돌아가며 배치) |
| #4 콘텐츠 유형 | 주제 × 유형 표(튜토리얼·흔한 실수·비포/애프터·비교·할 것/피할 것·전문가 의견) | 유형 고르기, 주제와 엇갈려 배치해 같은 조합이 몰리지 않게 |
| #5 한달치 계획표 | 달력 칸마다 주제·유형 꼬리표·제목, 주말은 휴식 | 캘린더 화면(칸 = 주제·유형·제목·시간) |

## 2. 화면에서 쓰는 법
1. 왼쪽 메뉴 「캘린더」 → 계정(본계정·top.pick01·오정꿀)과 달을 고른다.
2. 「한 달 계획 만들기」 → 난이도·시간·주제·유형을 고르고 「만들기」. 달력이 채워진다.
3. 칸을 눌러 제목(첫 화면 후킹)을 적는다. 「내가 ○○ 안 하면 / ○○ 당해요」 형식 그대로.
4. 「이 주제로 만들기」를 누르면 만들기 창에 계정·시리즈·주제가 채워진다(시험 실행 또는 실행 명령 복사).
5. 실제로 만들어진 작업(AH-번호)은 그 날 칸 아래에 상태와 함께 붙는다.

저장: `data/plans/<YYYY-MM>_<계정>.json` (계정마다 따로, 오정꿀은 본계정과 섞지 않음).

## 3. 에이전트와의 관계
- trend-scout: 그날 급상승 주제가 있으면 계획 칸보다 우선한다(사용자 규칙: 당일 트렌드는 그날 바로). 계획 칸은 「트렌드가 없을 때 무엇을 만들지」의 기본값.
- reels-maker: 그날 칸의 주제·유형·제목을 받아 패키지를 만든다. 유형은 후킹 26패턴 중 맞는 것을 고르는 힌트(흔한 실수 → 경고형, 비교 → 비교형 등).
- 기본 하위 주제: 본계정 「전세·보증금·생활 꿀팁·돈 아끼기·생활 법률」, top.pick01 「세계의 ○○」 시리즈. 오정꿀은 비워 두었다(직접 채움).
