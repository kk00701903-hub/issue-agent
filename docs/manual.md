# Agent Hub 사용자 매뉴얼 (v0.4)

## 1. 설치와 실행 (Windows)
1. 압축을 풀고 폴더를 연다(경로에 한글이 있어도 된다).
2. `install.bat` 더블클릭 — Python 확인, SDK 설치, .env 생성, 자체 시험까지 한다.
3. `.env` 를 열어 `ANTHROPIC_API_KEY` 를 넣는다. 혼자 쓰면 `HUB_PASSWORD` 는 비워도 된다.
4. `run.bat` 더블클릭 — 브라우저가 http://127.0.0.1:4830 으로 열린다. 이 창을 닫으면 서버가 꺼진다.

## 2. 화면
| 탭 | 하는 일 |
| --- | --- |
| 현황 | 오늘 API 비용, 그룹별 에이전트 카드, 최근 실행, 비용 없는 시험 버튼 |
| 승인함 | 에이전트가 만든 결과물을 보고 승인·반려. 검수 실패 건은 승인 버튼이 꺼진다 |
| 흐름 | n8n처럼 상자를 끌어 놓고 선으로 잇는 워크플로우 편집기. 저장하면 승인함의 진행 단계 표시에 반영된다 |
| 로그 | 에이전트 활동, 훅이 막은 기록, 작업 기록(work-log.md) |
| 설정 | 라이선스 키 등록, 제품 정보, 운영 한도 |

## 3. 릴스 한 편 만들기 (실제 실행)
```
python -m hub.runner --account top.pick00 --series 전세 --topic "전세 계약 전 확인 3가지"
```
- 계정: `top.pick00` `top.pick01` `ojeongkkul`. 인물 릴스는 `--type person`.
- 끝나면 승인함에 「승인 대기」 또는 「검수 실패」로 뜬다. 검수 실패는 오류 목록을 보고 반려하거나, 에이전트가 고치게 다시 실행한다.
- 승인은 「게시 준비 완료」 표시다. 실제 게시·예약은 인스타 콘텐츠 예약에서 직접 한다.

## 4. 흐름(워크플로우)
**AI로 만들기(기본)**
1. 「흐름」 탭에서 그룹을 고르고 「✨ AI로 만들기」를 누른다.
2. 원하는 흐름을 한두 문장으로 적는다. 예) 「오늘 전세 뉴스로 주제 조사 → 쇼츠 자막 참고해 릴스 패키지 제작 → 규칙 검수 → 내가 승인 → 영상 제작 → 예약 화면까지」
3. 「흐름 만들기」를 누르면 AI가 그룹의 에이전트 목록을 보고 노드와 선을 만든다. 안전 규칙(게시·제출·커밋 같은 마지막 버튼은 사람 단계, 크롬 통제 뒤에는 사람 단계)은 AI 결과 위에 코드로 한 번 더 맞춘다.
4. 만든 흐름이 한 번 재생된다. 확인하고 「저장」을 누른다. 저장 전에는 반영되지 않는다.
- AI 호출에는 `.env` 의 `ANTHROPIC_API_KEY` 를 쓴다(모델은 `hub/config.json` 의 `flow_model`). 키가 없으면 규칙 기반으로 만들고 화면에 그렇게 표시한다.
- 맞는 에이전트가 없는 단계는 「새 에이전트」 표시가 붙는다. 그 단계는 에이전트를 새로 정의해야 실제로 돌아간다.

**보기**
- 선 위로 점이 흘러가며 작업 방향을 보여 준다. 지금 실행 중인 에이전트 상자는 빛나고 「실행 중 n」 표시가 붙으며, 그 앞뒤 선이 진하고 빠르게 흐른다.
- 승인 단계 상자에는 「승인 대기 n」이 붙는다. 점선으로 흐린 상자는 아직 연결 안 된 「예정」 에이전트다.
- 「▶ 흐름 재생」: 한 건이 처음부터 끝까지 상자를 차례로 지나가는 모습을 보여 준다.

**직접 고치기**
- 왼쪽 목록을 누르면 상자가 생긴다. 상자를 끌어 옮기고, 오른쪽 ● 를 끌어 다른 상자 왼쪽 ○ 에 놓으면 연결된다. 상자·선을 누르고 Delete 키로 지운다. 오른쪽 「속성」에서 이름·담당·종류·메모를 고친다.
- 「맞춤」 「정렬」 「−/+」로 화면을 정리한다.

## 5. 크롬 통제
`docs/browser-setup.md` 참고. 요약: 크롬을 `--remote-debugging-port=9222 --user-data-dir=E:\chrome-agent-profile` 로 띄우고 작업 계정만 로그인한다. 게시·제출·결제·삭제 버튼은 에이전트가 누르지 못한다.

## 6. 라이선스
- 처음 실행한 날부터 30일은 평가판이다. 상단 띠에 남은 일수가 보인다.
- 끝나면 실행이 멈추고 화면은 열린다. 설정 탭에서 키를 넣으면 바로 풀린다.
- 키는 고객사 이름(`hub/config.json` → `branding.customer_name`)과 짝이다.

## 7. 자주 묻는 것
- **훅이 뭔가요?** 에이전트가 도구를 쓰기 전에 돌아가는 검사다. 커밋·삭제·규칙 파일 수정·최종 버튼 클릭을 막는다. 끌 수 없고, 규칙 값은 `hub/rules.json` 에서 바꾼다.
- **비용이 걱정됩니다.** `hub/config.json` 의 `daily_budget_usd` 를 넘으면 그날은 실행이 거부된다.
- **외부에서 접속할 수 있나요?** 안 된다. 127.0.0.1 에만 열린다. 열려면 코드와 보안 설정을 바꿔야 한다(판매 체크리스트 참고).
