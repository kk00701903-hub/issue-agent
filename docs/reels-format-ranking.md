# 릴스 형식: 「TOP10 랭킹 카운트다운」 (2026-11-03)

참고 영상: AI SCENE 「10월 한 달, 깃허브 TOP10이 받은 별」(69초). 영상 6위가 HyperFrames 이고 「이 영상을 만든 도구」라고 소개 → 이 형식은 **HyperFrames 로 코드로 만든 영상**이다. 우리 reels-renderer(HyperFrames) 틀로 그대로 만들 수 있다.

## 1. 구성 (영상 분석)
| 구간 | 화면 | 쓰는 장치 |
| --- | --- | --- |
| 0~3초 | 「10월 한 달, 깃허브 TOP10이 받은 별 24만 개」 + 빛나는 별 카드 | 큰 숫자로 바로 후킹 |
| 항목마다 약 5초 | 위: 「n위 이름, 한 줄 설명(핵심 낱말 빨간색)」 / 가운데: 저장소 카드(이름·별 숫자가 0→끝까지 올라감·핵심 그림) / 아래: 10칸 막대 줄(지금 순위 칸 빨간 테두리, 지나온 칸은 노랗게 차오름) / 오른쪽 아래: 마스코트가 순위마다 표정·손짓 | 숫자 올라가기, 진행 막대, 마스코트 반응 |
| 반전 칸 | 검은 배경 「근데 이 저장소, 10월엔 코드를 한 줄도 안 바꿨어요 → 그런데도 별이…」, 「코드 변화 0」 도장 | 중간 반전으로 끝까지 보게 |
| 1위 | 검은 배경 + 왕관, 「한 달 만에 별 4만 7천 개」 | 클라이맥스 |
| 보너스 | 「이달의 신인」 ROOKIE 도장 | 덤 정보 |
| 끝 | 「10월 30일 기준」 출처 카드 → 계정 이름 → 「좋아요와 팔로우 부탁드려요」 | 출처 밝히기, 행동 유도 |

## 2. 우리 규칙에 맞춘 틀
- **첫 화면 후킹**은 우리 규칙대로 「내가 ○○ 안 하면 / ○○ 당해요」 형식으로 바꾼다. 예) 「이 10개 모르면 / 남들 공짜로 쓰는 AI에 돈 내요」. 숫자만 적은 첫 화면은 쓰지 않는다(사용자 규칙).
- **장면 속도**: 항목 화면 글자를 다 읽을 수 있게 검수기 기준(글자 수 ÷ 초당 6자, 최소 2.5초). 막대·숫자 움직임은 빨라도 글자는 머문다.
- **순서 표시**: 화면에 「10위」처럼 쓰고, 음성 대본에는 「십 위」처럼 읽을 말로 적는다(「1/3」을 「3다시1」로 읽던 문제 방지, 검수기 voice_order_mark).
- **음성·음악**: 계정 규칙 그대로(본계정 SunHi, top.pick03 Chirp3-HD + 표준 BGM 낮게, 오정꿀은 음성 없이 인스타 무료 음원).
- **마스코트**: 그림은 Firefly 로 우리 캐릭터를 만든다(참고 영상의 빨간 말풍선 캐릭터를 따라 그리지 않음).
- **출처 카드**: 「○월 ○일 기준」과 자료 출처를 마지막에 꼭 넣는다.
- **끝 행동 유도**: 「댓글에 『TOP10』 남기면 목록 보내 드려요」(docs/benchmark-dm-funnel.md) + 소개 댓글. 캡션 링크 금지.

## 3. 어울리는 계정·주제
- top.pick03(AI 기술): 「이달의 깃허브 TOP10」, 「무료 AI 도구 TOP5」 — 이 형식 그대로.
- top.pick00(생활 꿀팁): 「전세 사기 많은 동네 TOP5」 「보증금 못 받은 사례 TOP5」 — 대출찬반 룰(실사진 펀치 줌·숫자 도장)과 섞어서.
- top.pick01(인물): 「세계의 ○○ TOP5」 — 인물 사진 필수, 어느 나라 지도자인지 소개, BGM 은 「세계의 ○○」 로테이션 규칙.
