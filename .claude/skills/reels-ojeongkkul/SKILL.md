# 오정꿀 전용 릴스 규칙

- 음성 없음. `voice` 는 비워 두고(`null`), 장면에 `voice_text` 를 넣지 않는다.
- 음악은 인스타 무료 음원만 쓴다. `bgm` 은 `{"source":"instagram_free","name":"<곡 이름 또는 메모>"}` 로 적고 `id` 는 쓰지 않는다. 본계정의 wav 곡 번호(M1 등)는 쓰지 않는다.
- 형식은 음성 없는 A 리액션 / B 파스텔 두 가지다. `style` 에 `A` 또는 `B` 를 적는다.
- 후킹·캡션·소개 댓글·표지 규칙은 본계정과 같다(`reels-main` 의 문장·캡션 부분 참고). 장면 속도 규칙도 같다.
- 본계정(top.pick00)과 계정·자료를 섞지 않는다. 개인 계정은 쓰지 않는다.
