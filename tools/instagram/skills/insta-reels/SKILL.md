# 음성 계정 릴스 규칙

## 형식
- 음성(내레이션): 도구 설정의 음성(`rules.voice_name`, 계정별 `voice_name` 이 있으면 그것). `voice` 에 `{"engine":"edge-tts","name":"<음성 이름>"}` 을 적는다.
- 길이 제한은 없다. 대신 장면마다 화면 글자를 다 읽을 시간을 준다(장면 속도 규칙은 검수기가 검사한다).
- 읽을 대본(`voice_text`)에는 화면의 「1/3」 같은 순서 표시를 쓰지 않는다. 「첫 번째」, 「두 번째」처럼 풀어 쓴다.
- BGM: 로컬 곡 번호를 `bgm.id` 에 적는다. 한 곡만 쓰지 않고 순서대로 돌려 쓴다. 도구 설정의 금지곡은 쓰지 않는다. 시리즈 로테이션이 설정되어 있으면 그 시리즈는 정해진 곡을 순서대로 쓴다.
- 표지: 게시물 목록에서 제목이 잘 보여야 한다. 배경과 대비를 확보하고 `cover_title` 에 표지 제목을 적는다.

## 문장
- 후킹은 tools/instagram/docs/hooking-patterns.md 26패턴 중 하나. 첫 화면은 「내가 ○○ 안 하면 / ○○ 당해요」처럼 보는 사람과의 관련·결과·교훈이 담기게 두 줄로 쓴다. 뉴스 숫자만 적은 문장은 쓰지 않는다.
- 한 화면에 헷갈리는 비슷한 말(예: 「나라가」와 「나라면」)을 같이 두지 않는다.
- 인물 소개가 켜진 계정의 인물 릴스(`type: "person"`)는 누구인지 `leader_intro` 에 간단히 소개하고 영상에도 넣는다.

## 캡션과 댓글
- 캡션에는 링크를 넣지 않는다(클릭이 안 된다). 링크는 프로필 대표 링크로만.
- 해시태그는 5개 이하.
- 모든 게시물에 짧은 소개 댓글(`intro_comment`)을 쓴다.
