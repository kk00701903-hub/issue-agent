# 댓글 → DM 자동 응답 + 팔로우 확인 설계 안내

게시물에 댓글을 달면 자동 DM이 오고, 팔로우를 확인한 뒤에 자료를 보내 주는 흔한 방식을 Meta 공식 도구로 안전하게 설계하는 방법.

## 1. 흐름
| 순서 | 상대(자동) | 받는 사람 |
| --- | --- | --- |
| 1 | 게시물 댓글에 반응해 DM을 보냄 | 키워드 댓글을 닮 |
| 2 | 「팔로우 확인을 위해 아래 버튼을 눌러주세요. 여부가 확인되면 원하시는 메시지를 전송해드려요」 + 버튼 「팔로우 확인 🙌」 | 버튼을 누름 |
| 3 | 팔로우가 확인 안 되면: 「인스타그램 팔로우가 되어있지 않다면, 전송이 원활하지 않을 수 있어요. 팔로우 시도 후 버튼을 다시 눌러주세요」 + 버튼 「팔로우 완료했어요 🙌」 | 팔로우하고 다시 누름 |
| 4 | 확인되면 약속한 자료(링크·파일)를 보냄 | 받음 |

얻는 것: 댓글 수(노출 신호)와 팔로워가 함께 늘고, 캡션에 넣을 수 없는 링크를 DM으로 보낼 수 있다.

**참고 계정의 약점(따라 하지 말 것)**: 캡처에서 「팔로우 완료했어요」를 두 번 눌러도 같은 안내만 되풀이된다. 팔로우 직후에는 확인이 늦게 잡히는 일이 있어, 받는 사람은 막힌 느낌을 받는다. → 우리는 **두 번째 확인에서도 안 되면 자료를 그냥 보내고** 「팔로우하시면 다음 자료도 먼저 받아요」로 끝낸다.

## 2. 어떻게 동작하나 (사실 확인)
- 인스타는 「누가 팔로우했다」는 알림을 앱에 주지 않는다. 그래서 버튼을 누른 순간 Meta 공식 API로 「이 사람이 내 계정을 팔로우하는지」를 물어본다(ManyChat·Inrō 등의 「팔로우 요청(Ask for follow)」 단계). 차단한 사람은 확인값이 비어 온다.
- 댓글 → DM은 Meta 공식 API의 **비공개 답장(Private Replies)** 기능이다. 댓글 하나에 DM 한 번, 댓글 뒤 7일 안. 그 뒤 메시지는 상대가 답한 뒤 24시간 안에만 보낼 수 있다. 계정당 시간당 750건 한도.
- **팔로우만 한 사람에게 먼저 DM을 보내는 것은 허용되지 않는다**(상대가 먼저 댓글·메시지를 남겨야 함).
- 비밀번호를 넣어 돌리는 비공식 봇은 인스타 이용약관 위반 소지가 크다. 수익 계정(계정·계정·다른 계정)을 지키려면 공식 API를 쓰는 도구만 쓴다.

## 3. 도구 선택
| 방법 | 장점 | 단점 |
| --- | --- | --- |
| ManyChat (권장 시작점) | 「Comment → DM」·팔로우 확인 단계가 이미 있음, 코드 없음 | 유료 요금제 필요할 수 있음(가입 전 요금 확인) |
| Inrō 등 비슷한 서비스 | 팔로우 확인 대기·재확인 단계 제공 | 국내 결제·한국어 지원 확인 필요 |
| 직접 Meta API 연동 | 비용 없음, 우리 규칙대로 | 공개 웹훅 주소·Meta 앱 심사 필요. Agent Hub 는 127.0.0.1 전용이라 지금 구조로는 받을 수 없음 |

→ 지금은 **ManyChat 같은 공식 API 도구에서 설정**하고, Agent Hub 의 에이전트는 **문구·키워드 설계와 설정 화면 채우기**까지만 한다. 마지막 「켜기(Publish/Set Live)」는 사람이 누른다(훅이 막는 최종 버튼 규칙과 같음).

## 4. 릴스 에이전트에 넣은 것
- 새 에이전트 `dm-funnel`(「댓글→DM 자동 응답」, 예정): 릴스·SNS 그룹, 흐름 마지막 단계 「댓글→DM 자동 응답 설정」.
- 릴스 패키지에 선택 항목 `dm_cta` 를 둔다(문서: package-schema.md). reels-maker 가 주제에 맞는 키워드·DM 문구를 같이 만든다.

```json
"dm_cta": {
  "keyword": "전세",
  "comment_line": "댓글에 「전세」 남기면 계약 전 체크리스트 DM으로 보내드려요",
  "dm_gate": "팔로우 확인을 위해 아래 버튼을 눌러주세요. 확인되면 체크리스트를 바로 보내드려요",
  "button": "팔로우 확인",
  "retry": "팔로우 직후엔 확인이 늦을 수 있어요. 팔로우하고 한 번만 더 눌러 주세요",
  "retry_button": "팔로우 완료했어요",
  "deliver": "요청하신 체크리스트예요 👉 (링크)",
  "fallback_after": 2
}
```

## 5. 우리 규칙과 맞추기
- 캡션에는 링크를 넣지 않는다(기존 규칙). 링크는 DM `deliver` 에만, 쿠팡은 파트너스 링크로.
- 첫 화면 후킹은 그대로 「내가 ○○ 안 하면 / ○○ 당해요」 식. 댓글 유도 문구(`comment_line`)는 캡션 끝과 **소개 댓글**에 넣는다(소개 댓글은 모든 게시물에 단다는 기존 규칙과 합침).
- 계정이 여럿이면 같은 방식으로 하되 키워드·문구를 섞지 않는다.
- `fallback_after` 는 2 이하로. 같은 안내를 세 번 이상 되풀이하지 않는다.
- 팔로우를 「조건」으로 거는 것은 도구의 정책·인스타 정책이 바뀔 수 있으니, 도구 공지를 분기마다 확인한다. 문제가 생기면 팔로우 확인 단계만 끄고 댓글→DM 은 유지한다.

## 6. 다음 할 일(사람)
1. ManyChat(또는 고른 도구) 가입 → 인스타 프로페셔널 계정을 공식 로그인 화면으로 연결.
2. 첫 릴스 하나로 시험: 키워드 1개, 팔로우 확인 1단계, 재확인 1번, 그 뒤 그냥 보내기.
3. 1주 뒤 댓글 수·팔로워 증가·DM 클릭을 보고 계속할지 정한다.
