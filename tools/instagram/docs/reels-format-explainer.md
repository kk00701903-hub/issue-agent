# 릴스 형식: 「진행자 + 위 카드 해설」

참고 영상은 사용자가 준 35초짜리 세로 영상(720×1280, 2026-11-03)이다. 새 AI 영상 모델을 소개하는 해설 릴스로, **화면 아래쪽에 진행자, 위쪽에 정보 카드**가 놓인다. 장면마다 위 카드만 바뀌고 진행자는 계속 말한다.
참고 영상의 대본·카드 그림·인물은 쓰지 않는다. 가져오는 것은 아래 구성과 장치뿐이다.

## 1. 구성 (영상 분석, 약 35초)
| 구간 | 화면 | 쓰는 장치 |
| --- | --- | --- |
| 0~3초 | 진행자가 화면을 꽉 채우고, 가운데에 빨간 큰 자막(「지금 당장 ○○해야 돼요」). 첫 1초는 위에 관련 서비스 카드를 잠깐 겹침 | 손해를 경고하는 말로 바로 후킹 |
| 3~9초 | 위: 순위·점수 비교 카드(새 모델 vs 큰 회사 모델, 점수 막대가 차오름) / 아래: 진행자 | 비교 숫자, 막대 애니메이션 |
| 9~13초 | 「무료 / NO BILL」 카드. 사용량 숫자가 669 → 0으로 내려가고, 「검열 없음」 같은 특징 칸을 하나씩 켬 | 숫자 내려가기, 칸 켜기 |
| 13~20초 | 저장소 카드(이름·별 숫자·태그) → 랭킹 표에서 새 모델 줄이 1위로 올라오며 「TOP RATED」 도장 | 표 순위 바뀜, 도장 |
| 20~27초 | 실제 결과 예시: 영상 썸네일 → 「참고 영상 넣기」 카드 → 장면 여러 개가 한 번에 만들어지는 카드 → 효과음·대화 음성·입 모양 차트 | 결과를 보여 줘 믿게 함 |
| 27~31초 | 「내 PC에서 돌아감」 칸 막대(사양이 맞으면 초록) → 「3단계로 시작」 체크리스트 → 정리 문서 카드 | 따라 할 수 있다는 안심 |
| 31~35초 | 진행자가 다시 꽉 채움: 「궁금하시면?」 → 프로필 카드(팔로우 버튼 눌림) → 「댓글에 『모델』이라고 달아 주세요」 → 댓글 목록에 그 낱말이 쌓임 → DM 창에 「starter-kit.zip」이 날아감 | 팔로우 + 댓글 낱말 → DM 자료(우리 DM 퍼널과 같음) |

## 2. 공통 장치
- **화면 나누기**: 위 55%는 카드(밝은 바탕, 둥근 모서리, 위에 작은 영어 라벨 「BENCHMARK」·「REPOSITORY」 같은 분류표), 아래 45%는 진행자. 자막은 그 사이 띠에 노란·흰 큰 글자로 한 줄만.
- **카드 하나에 숫자나 상태 하나**: 점수, 별 숫자, 가격(무료), 순위, 사양 맞음 표시. 숫자는 올라가거나 내려가는 움직임으로 보여 준다.
- **장면 길이**: 카드 하나에 2~4초. 진행자 말은 끊기지 않고, 카드만 바뀐다.
- **끝**: 팔로우 → 댓글 낱말 → DM 자료. 자료 이름(「starter-kit」)을 보여 줘서 받을 것을 분명하게 한다.

## 3. 우리 규칙에 맞춘 틀
- **진행자**: 실제 사람 얼굴은 쓰지 않는다. **직접 만든 진행자 그림이 말하는 것처럼 움직이게**(입 모양·손짓) HyperFrames로 만든다(영상 생성 AI 없이). 음성 계정은 계정에 정한 음성, 무음 계정은 진행자 없이 위 카드만 크게.
- **첫 화면 후킹**은 우리 규칙대로 「내가 ○○ 안 하면 / ○○ 당해요」. 예) 「이거 모르고 유료 결제하면 / 매달 5만 원 그냥 버려요」. 숫자만 적은 첫 화면은 쓰지 않는다.
- **장면 속도**: 위 카드 글자를 다 읽을 수 있게 검수기 기준(글자 수 ÷ 초당 6자, 최소 2.5초). 숫자·막대 움직임은 빨라도 글자는 머문다.
- **카드 그림**: 다른 회사 로고·서비스 화면을 그대로 그리지 않는다. 비교 대상은 이름 글자만, 화면을 쓰면 장면에 「출처: ○○」 라벨을 붙인다. 카드 바탕 그림은 Firefly로 만든다.
- **사실 확인**: 점수·별 숫자·가격·사양은 근거 링크가 있는 숫자만 쓰고, 패키지의 사실 확인 칸에 출처를 적는다. 「검열 없음」처럼 위험할 수 있는 장점은 쓰지 않는다.
- **음성 읽기**: 화면에 「94.5」「#1」처럼 써도 음성 대본에는 「구십사 점 오」「일 위」처럼 읽을 말로 적는다(검수기 voice_order_mark).
- **끝 행동 유도**: 「댓글에 『키트』라고 달면 정리 자료 보내 드려요」 + 소개 댓글. 캡션에는 링크를 넣지 않는다. DM 자료 보내기는 docs/dm-funnel.md 절차(보내기 버튼은 사람이 누름).

## 4. 어울리는 주제
- AI·기술 계정: 「새로 나온 무료 AI ○○」, 「유료 도구 대신 쓸 오픈소스」
- 생활 꿀팁 계정: 「몰라서 손해 보는 제도」를 비교 카드(내는 돈 vs 받는 돈)로
- 인물 계정: 진행자 + 위에 인물 사진 카드(인물 사진 필수, 누구인지 소개)
