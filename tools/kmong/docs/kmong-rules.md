# 크몽 등록 규칙 요약(검수기 기준)

근거: 크몽 「노하우·콘텐츠 서비스 등록 가이드」(https://kmong.com/support/expert-center/posts/755, 2026-11-03 확인). 크몽 정책은 바뀔 수 있으니 등록 전 판매자 센터 안내를 다시 본다.

- **외부 연락처 금지**: 휴대폰 번호, 이메일, SNS 정보, 연락처가 든 홈페이지·포트폴리오 주소. 개별 연락은 주문 접수 뒤에만.
- **절대 표현 금지**: 최대·최고·최초·제일·유일 등.
- **무조건 보증 금지**: 「100% A/S」, 「무제한 A/S」처럼 범위·조건 없는 보증.
- **증빙 없는 주장 금지**: 수상·자격·학력·경력·수익·보증 정보는 증빙이 있을 때만.
- **가격**: 총비용(용역비·실비·세금 포함) 명시, 「일단 문의주세요」처럼 예측할 수 없는 가격 표현 금지. 패키지는 3개 옵션, 사이 가격 차이 최소 1만 원.
- **최소 금액**: 전자책 1만 원, 투잡·노하우·자료·템플릿 5천 원 이상(용역 서비스는 카테고리 안내를 확인).
- **전자책 미리보기**: 5장 이상, 한 장씩, 모자이크·블러·가리기 금지. 내용이 바뀌면 목차·미리보기도 같이.
- **카테고리**: 복합 서비스는 분야별로 나눠 각각 등록.
- **키워드·요약**: 의뢰인을 헷갈리게 하는 무관한 단어 금지.
- **FAQ·결제 후 메시지**: 연락처·개인정보·민감정보 요구 금지.
- **환불**: 전자상거래법 기준, 따로 정하면 법정 기준보다 의뢰인에게 유리해야 함.
