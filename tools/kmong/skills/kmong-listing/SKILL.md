# 크몽 서비스 자료 쓰기

1. tools/kmong/docs/kmong-rules.md 를 먼저 읽는다. 검수기가 같은 규칙을 코드로 본다.
2. 제목: 의뢰인이 검색할 말 + 결과물. 40자 안팎. 절대 표현(최고·유일 등) 금지.
3. 요약: 무엇을 얼마나, 언제까지 주는지 한 문장(100자 안).
4. 상세 설명: 「이런 분께」 → 「작업 순서」 → 「제공 내용·분량」 → 「안내(작업일 세는 법·수정 범위)」. 외부 연락처·링크·SNS 를 쓰지 않는다.
5. 패키지: STANDARD < DELUXE < PREMIUM, 사이 가격 1만 원 이상. 각 패키지에 분량·작업일·수정 횟수·제공 목록.
6. FAQ 3~5개: 수정 범위, 작업일, 준비물, 환불(법정 기준). 연락처·개인정보를 묻지 않는다.
7. 경력·수익·수상은 사용자가 증빙을 줬을 때만 쓰고 `evidence` 에 적는다. 모르면 notes 에 「확인 필요」.
8. 메인 이미지: 글자 없는 그림 시안 설명만 `main_image.prompt` 에(그림은 Firefly 로 사람이 만들고 제목 글자는 따로 얹는다).
